# Projet Capteur de Luminosité

Ce projet est réalisé dans le cadre du module Communication Sans Fil.

## Membres du groupe
- Amine Mbarki
- Souheil Bensarraj

## Objectif
Créer une maison intelligente capable d’adapter automatiquement l’éclairage selon la luminosité naturelle.

## Technologies utilisées
- Arduino Uno
- LDR
- LEDs
- LoRa
- C++

## Fonctionnement
Le capteur mesure la luminosité puis l’Arduino décide automatiquement d’allumer ou non l’éclairage.

## Améliorations futures
- Application mobile
- Contrôle à distance
- Multi-pièces
